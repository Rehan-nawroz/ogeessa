# Ogeessa - stock trading agent (Python 3.12)
#
# These pins are the exact set this project is built and tested with. They
# differ from the project's earlier pin file because the code moved on:
#
# 1. rich 13 -> 15: the Textual TUI (textual 8.x) requires rich>=14.2.0, so
#    rich==13.7.1 could never resolve alongside it.
# 2. langchain 0.2.x -> 1.4.x plus langchain-classic: the agent now imports the
#    langchain_classic namespace (AgentExecutor / create_tool_calling_agent),
#    which ships as its own package.
# 3. duckduckgo-search -> ddgs: the search package was renamed upstream;
#    tools/news.py does `from ddgs import DDGS`.
# 4. pandas-ta-classic 0.8.x: the maintained republication of the deleted
#    pandas-ta 0.3.14b0 codebase. Import it as: import pandas_ta_classic as ta
# 5. yfinance 1.7.x: the 0.2.x line is blocked by Yahoo's anti-bot changes and
#    returns empty data for every symbol.
# 6. No setuptools pin: pandas-ta-classic 0.8.x does not need pkg_resources.
#
# Install:  pip install -r requirements.txt
